# AutomatixQR 🚀
### Enterprise AI-Powered QR SaaS Platform by [Automatixes](https://www.automatixes.com/)

Designed for deployment as a subdomain at `qr.automatixes.com`.

## 🌐 Key Enhancements
- 🎨 **Light Modern SaaS Theme**: Clean white and slate aesthetic with Automatixes indigo (`#4f46e5`) and violet accents.
- 🌍 **Multi-Language (i18n) Engine**:
  - **Auto Browser / Country Detection**: Automatically detects user locale (e.g., Spanish, French, German, Arabic, Urdu, Chinese, Japanese, English).
  - **Manual Language Switcher**: Easily switch languages with one click in the top header.
  - **RTL Support**: Full Right-to-Left layout adaptation when Arabic or Urdu is active.
- 🏢 **Automatixes Ecosystem Integration**:
  - Header links to `https://www.automatixes.com/`.
  - Brand presets and signatures.
- ⚡ **7 Full SaaS Modules**:
  1. **QR Studio**: Core creator with Drag & Drop logo upload, custom colors, and error correction.
  2. **Dynamic Links**: Editable destination URLs without reprinting QR codes.
  3. **Batch Generator**: Multi-line / CSV bulk generator with ZIP export.
  4. **Templates Gallery**: Curated one-click designer themes.
  5. **Saved Library**: Persistent QR history with instant re-load.
  6. **Scan Analytics**: Real-time Chart.js telemetry.
  7. **Developer API**: Integration code snippets & API key management.

## 🚀 How to Run Locally

```bash
# Start server
python -m http.server 3000
```
Open **[http://localhost:3000](http://localhost:3000)** in your browser.
